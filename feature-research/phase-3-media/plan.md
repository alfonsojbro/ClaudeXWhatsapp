# Plan: Phase 3 — Media pipeline (`apps/brain/src/media/`)

Date: 2026-09-03 · Branch: `phase-3-media` · Source spec: `docs/IMPLEMENTATION_PLAN.md` §3.5, §3.2, §5, §6

## Goal
Build the self-contained media pipeline for the brain: image, PDF/DOCX, voice note, video, location, contact card, link, plus optional TTS voice replies, with size limits, per-type timeouts, temp-file cleanup, and vitest coverage.

## Reality check (state your assumptions in code comments, do not work around them)
- The repo currently contains only `README.md` and `docs/`. Phases 0–2 (workspace skeleton, bridge, brain loop, router) DO NOT exist. There is no git repo.
- Therefore this task also creates the minimal pnpm workspace skeleton needed to build and test `apps/brain`, and a tiny `apps/brain/src/router.ts` whose only job is the `media` branch. Do NOT build the bridge, the Agent SDK loop, sessions, the confirm gate, or the vault MCP.
- The bridge is consumed through an interface (`BridgeClient`) defined in this module. Phase 1 will implement it.
- The chat flow is consumed through the return value (`MediaResult`): content blocks + the question text. Phase 2's loop will pass them to the model. Content blocks use the `@anthropic-ai/sdk` param types (`Anthropic.ContentBlockParam`, `Anthropic.ImageBlockParam`, `Anthropic.DocumentBlockParam`, `Anthropic.TextBlockParam`) — never redefine them.
- Local toolchain: node 20.19, pnpm 10, ffmpeg/ffprobe 8.1, `whisper-cli` present, `pandoc` MISSING. Code must run on Node ≥ 20 (global `fetch`, `FormData`, `Blob` are available; no extra HTTP libs). `type: "module"` + NodeNext.
- Whisper and TTS use the OpenAI HTTP API directly via `fetch` (no `openai` npm package). Anthropic content-block shapes come from the claude-api skill:
  - image: `{ type: "image", source: { type: "base64", media_type: "image/jpeg" | "image/png" | "image/webp" | "image/gif", data } }`
  - PDF: `{ type: "document", source: { type: "base64", media_type: "application/pdf", data }, title? }` — base64 with no newlines, ≤ 32 MB request.
  - plain-text document (DOCX→Markdown, page text): `{ type: "document", source: { type: "text", media_type: "text/plain", data }, title }`
  - The user text goes in a `{ type: "text", text }` block placed AFTER the media blocks.

- `limits.ts` — `assertSize(bytes, maxMb, label)` throws too_large; `withTimeout(promise, ms, label, onTimeout?)` throws timeout (calls onTimeout to kill a child); `mbToBytes`.
- `tmp.ts` — `createTempDir(config)` under `MEDIA_TMP_DIR` (mkdir -p, `fs.mkdtemp`); `withTempDir(config, fn)` always `rm -rf` in `finally`; `cleanupStaleTempDirs(config, maxAgeMs = 6h)` for a startup sweep. Never delete anything outside `MEDIA_TMP_DIR`.
- `exec.ts` — `runCommand(bin, args, { timeoutMs, cwd?, maxBufferBytes = 16 MB })` using `child_process.execFile`; on timeout kill with SIGKILL and throw `MediaError('timeout')`; ENOENT → `MediaError('tool_missing', userMessage naming the binary)`. `commandExists(bin)` (execFile `bin -version`/`--version`, swallow non-zero exit, ENOENT → false). Export type `CommandRunner` so tests inject a fake.
- `ffmpeg.ts` — PURE argument builders (no I/O) + thin runners that use them:
  - `buildAudioToWav16kArgs(input, output)` → `['-y','-hide_banner','-loglevel','error','-i',input,'-vn','-ac','1','-ar','16000','-f','wav',output]`
  - `buildKeyframeArgs(input, outPattern, { intervalSeconds, maxFrames, maxEdgePx })` → `['-y','-hide_banner','-loglevel','error','-i',input,'-vf',`fps=1/${interval},scale='min(${maxEdge},iw)':-2`,'-frames:v',String(maxFrames),'-q:v','3',outPattern]`; `outPattern` like `frame-%02d.jpg`.
  - `buildToOggOpusVoiceNoteArgs(input, output)` → `['-y','-hide_banner','-loglevel','error','-i',input,'-vn','-c:a','libopus','-b:a','32k','-vbr','on','-ac','1','-ar','48000','-application','voip','-f','ogg',output]`
  - `buildProbeArgs(input)` → `['-v','error','-show_entries','stream=codec_type,duration:format=duration','-of','json',input]`
  - `chooseFrameInterval(durationSeconds, baseIntervalSeconds, maxFrames)` → `max(base, ceil(duration / maxFrames))` so a long video still yields ≤ maxFrames evenly.
  - runners: `probeMedia(ctx, path) → { durationSeconds, hasAudio, hasVideo }` (parse ffprobe JSON), `audioToWav16k(ctx, input, output)`, `extractKeyframes(ctx, input, dir, opts) → string[]` (sorted frame paths), `toOggOpusVoiceNote(ctx, input, output)`.
- `image.ts` — `prepareImage(path, { maxEdgePx }) → { data (base64), mediaType }` with sharp: `.rotate()` (EXIF), `.resize({ width: maxEdge, height: maxEdge, fit: 'inside', withoutEnlargement: true })`, output JPEG q85 (PNG kept as PNG only if it has alpha; use `metadata().hasAlpha`), `.toBuffer()`. `buildImageBlock(data, mediaType) → Anthropic.ImageBlockParam`. `handleImage(media, ctx) → MediaResult`: download via bridge → assertSize → prepareImage → blocks `[image, text]`, question = caption ?? DEFAULT_IMAGE_QUESTION ("Describe this image. If it shows text, a whiteboard, a slide, or a diagram, give a structured summary: title, key points, action items, open questions."). Stickers/WebP go through the same path.
- `document.ts` — `handleDocument(media, ctx)`: PDF (`application/pdf` or `.pdf`) → assertSize (PDF limit) → base64 → `Anthropic.DocumentBlockParam` with `title: fileName`; DOCX (`application/vnd.openxmlformats-officedocument.wordprocessingml.document` or `.docx`) → `commandExists(PANDOC_BIN)` else throw `tool_missing` with userMessage "DOCX needs pandoc on the box: `apt install pandoc`"; run `pandoc -f docx -t gfm --wrap=none <in>` (stdout) → text document block with `title`; `text/plain`, `text/markdown`, `text/csv` → text document block; anything else → `unsupported`. Question = caption ?? "Summarize this document: purpose, key points, dates, action items."
- `transcribe.ts` — `transcribe(ctx, wavPath, { language? }) → { text, provider: 'whisper.cpp'|'openai' }`. Provider order: `WHISPER_CPP_BIN` set → run `[bin, '-m', model, '-f', wav, '-otxt', '-of', outBase, '-np', '-nt', ...(language !== 'auto' ? ['-l', language] : [])]` then read `${outBase}.txt`; else `OPENAI_API_KEY` set → `POST ${OPENAI_BASE_URL ?? https://api.openai.com}/v1/audio/transcriptions` multipart (`file` Blob from fs, `model`, `response_format: 'json'`, `language` if not auto) with `Authorization: Bearer` → `json.text`; else throw `tool_missing` ("Set OPENAI_API_KEY or WHISPER_CPP_BIN/WHISPER_CPP_MODEL"). Trim; empty text → `transcription_failed` ("I could not hear anything in that voice note"). Export `buildWhisperCppArgs` pure.
- `voice.ts` — `handleVoiceNote(media, ctx)`: download → assertSize (audio) → withTempDir → `audioToWav16k` → `transcribe` → result `{ blocks: [{type:'text', text: transcript}], question: transcript, transcript, replyPrefix: formatTranscriptQuote(transcript) }`. `formatTranscriptQuote(t)` → `> 🎤 ${t}` (multi-line transcripts: each line prefixed with `> `), capped at 600 chars with `…`. Plain audio files (not ptt) use the same handler with question = caption ?? "Here is the transcript of the audio. Summarize it."
- `video.ts` — `handleVideo(media, ctx)`: download → assertSize (video) → withTempDir → `probeMedia` → `chooseFrameInterval` → `extractKeyframes` → for each frame `prepareImage` → image blocks (with a short text block before each: `Frame N at ~Ts`) → if `hasAudio`: wav → transcribe (transcription failure is non-fatal: push to `notes`, continue) → final text block: `Video: <duration>s, <n> frames every <interval>s.` + transcript section + question (caption ?? "Describe what happens in this video and summarize anything said."). Set `transcript` and `replyPrefix` when a transcript exists.
- `location.ts` — `reverseGeocode(ctx, lat, lon) → { displayName, address? }` via Nominatim `/reverse?format=jsonv2&lat=&lon=&zoom=18` with headers `User-Agent: NOMINATIM_USER_AGENT`, `Accept-Language: en`; module-level rate limiter: wait so calls are ≥ `NOMINATIM_MIN_INTERVAL_MS` apart (export `createRateLimiter(minIntervalMs, now = Date.now, sleep)` pure for tests); non-200 → `geocode_failed` but `handleLocation` degrades to coordinates only. `handleLocation(media, ctx)` → text block: `Location shared: <name or displayName>\nCoordinates: lat, lon\nMaps: https://www.openstreetmap.org/?mlat=..&mlon=..#map=17/lat/lon`; question = caption ?? "Note this location. Answer briefly what and where it is." No memory write (§3.5: only if asked).
- `contact.ts` — `parseVCard(text) → VCardContact[]` (unfold CRLF/LF continuation lines; fields FN, N, TEL (with TYPE params), EMAIL, ORG, TITLE, URL, NOTE, ADR; multiple `BEGIN:VCARD` blocks; strip `waid=` param but keep the number). `formatContacts(contacts)` → Markdown lines. `handleContact(media, ctx)` → text block + question = caption ?? "Contact card received. Summarize who this is; do not save unless I ask."
- `link.ts` — `extractUrls(text) → string[]` (http/https, dedupe, strip trailing punctuation); `fetchPage(ctx, url) → { url, finalUrl, title, description, text }`: GET with `Accept: text/html`, timeout, follow redirects, refuse non-http(s) and private/loopback hosts (`localhost`, `127.`, `10.`, `192.168.`, `172.16-31.`, `169.254.`, `[::1]`), read at most `MEDIA_MAX_LINK_KB` (abort the body after the cap), only `text/html`/`text/plain`/`application/json`; `htmlToText(html)` strips `<script>/<style>/<nav>/<footer>`, tags, decodes common entities, collapses whitespace, extracts `<title>` and `meta[name=description]`, caps text at 40 000 chars. `slugify(title)`; `buildBookmarkCapture(page, capturedDate)` → `{ slug: 'bookmark-<slug>', body: 'source: <url>\ncaptured: YYYY-MM-DD\n\n# <title>\n\n<description>\n\n(summary goes here)', prompt: 'Reply "save" to store this as raw/bookmark-<slug>.md' }`. `handleLink(media, ctx)`: first URL only (others listed in notes) → text document block (`title`) + question = caption-without-url ?? "Summarize this page in 5 bullets and say if it is worth keeping." → `captureOffer`.
- `tts.ts` — `synthesizeSpeech(ctx, text, dir) → { path, mimeType: 'audio/ogg; codecs=opus' }`: `prepareTtsText(text, maxChars = 4000)` strips Markdown (`*`, `_`, `#`, backticks, links → label) and cuts at the last sentence end before the cap; `POST /v1/audio/speech` `{ model, voice, input, response_format: 'opus' }` → write `speech.opus` → `toOggOpusVoiceNote` → `voice.ogg`. Errors → `tts_failed`.
- `voicePrefs.ts` — `parseVoiceCommand(text) → 'on'|'off'|'status'|null` (matches `^\s*/?voice\s*(on|off)?\s*$` case-insensitive); `VoicePreferenceStore` interface `{ isVoiceOn(chatJid), setVoice(chatJid, on) }`; `createFileVoicePreferenceStore(filePath)` (JSON `{ [jid]: boolean }`, atomic write via temp + rename) and `createMemoryVoicePreferenceStore()`. `handleVoiceCommand(text, chatJid, store) → string | null` reply ("Voice replies on. Say `voice off` to stop.").
- `voiceReply.ts` — `maybeSendVoiceReply(ctx, store, chatJid, replyText)`: if voice on and `OPENAI_API_KEY` set → withTempDir → synthesizeSpeech → `bridge.sendMedia(chatJid, { path, mimeType, ptt: true })` under `MEDIA_TIMEOUT_TTS_MS`; failures are logged and returned as `{ sent: false, reason }`, never thrown (the text reply already went out).
- `classify.ts` — `classifyInbound(raw) → InboundMedia | null` from a bridge-neutral shape `{ messageId, chatJid, mimeType?, fileName?, caption?, text?, isVoiceNote?, location?, vcard?, sizeBytes? }`: `text/vcard`/vcard present → contact; location → location; `image/*` (incl. webp stickers) → image; `audio/*` + isVoiceNote → voice, else audio; `video/*` → video; pdf/docx/text → document; no mime but text with URL → link; else null (plain text is not media).
- `pipeline.ts` — `handleMedia(media, ctx) → MediaResult`: switch on kind → handler wrapped in `withTimeout(config.timeouts[kind])`; all temp dirs cleaned in `finally`; `MediaError` is rethrown, unknown errors wrapped as `MediaError('unsupported', …)` with the original as `cause`. `timeoutFor(kind, config)` exported for tests. `formatMediaErrorReply(err)` → the `userMessage`.
- `index.ts` — barrel exports + `composeReply(result, modelReply)` → `replyPrefix ? \`${replyPrefix}\n\n${modelReply}\` : modelReply` + capture offer line appended when present.

## Non-negotiables
- No code copied from other projects (wa-gpt, ThePath, NobleAdmin). Write from scratch.
- No OCR library, no `openai` npm package, no axios/node-fetch. Only deps listed above.
- Every handler: size check BEFORE reading the whole file into memory; base64 only after size check; temp files always removed in `finally`.
- Never shell out with a string command; always `execFile` with an args array.
- No network calls in unit tests: inject `fetch` and the command runner.
- Keep each source file under ~250 lines; split if larger.

## Out of scope
Bridge (Baileys), Agent SDK loop, sessions, confirm gate, vault MCP write for the bookmark capture (the pipeline only returns the offer), scheduler, deploy scripts, CI. Do not create `packages/shared` — a later phase moves the shared bits there.
